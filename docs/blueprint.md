# **App Name**: CapchaCash

## Core Features:

- User Authentication: Secure user registration and login using Firebase Authentication.
- Captcha Generation: Serve random text or image-based captchas using an external API to prevent bot abuse.
- Real-time Balance Update: Update user's points/coins in real-time using Supabase database upon successful captcha completion.
- Rewarded Ads Integration: Integrate AdMob or Unity Ads to provide bonus points for watching ads.
- Withdrawal System: Allow users to request payouts (gift cards, wallet balance, Paytm cash) after reaching a threshold.
- Anti-Bot Protection Tool: Implement checks and rate limiting based on LLM based reasoning to enhance bot detection and protect the integrity of the app.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB) to evoke trust and serenity, ideal for earning apps.
- Background color: Light blue (#E6F3FF), a desaturated version of the primary color for a calm backdrop.
- Accent color: Yellow-green (#B0E293), analogous to sky blue and creates contrast for important actions.
- Body and headline font: 'PT Sans', a humanist sans-serif font combining a modern look and warmth.
- Use clear, recognizable icons for navigation and rewards.
- Clean, intuitive layout for easy captcha solving and balance tracking.
- Subtle animations on successful captcha submission and balance updates.
